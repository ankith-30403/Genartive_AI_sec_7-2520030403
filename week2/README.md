Wired up a shared LLMProvider interface so I could swap between Google Gemini and a local Ollama model through LLMClient without rewriting the core app logic. Having a common generate() contract made switching providers feel clean instead of messy, and adding a fake provider with unittest let me verify the client without burning real API calls. In the end, I could pick a provider, type a prompt, get back a response, and run unit tests smoothly.
