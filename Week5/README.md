Built a token and budget estimator in Python to project API token usage, costs, and rate limits (RPM and TPM) with a safety margin before shipping an AI feature. It really drove home how quickly token counts and request volume can push monthly spend past budget if you don't model them upfront, and writing unittest checks kept the math and limit flags honest. Running the script prints a PASS/REVIEW report across RPM, TPM, daily budget, and monthly budget—showing daily usage looking fine here while monthly budget gets flagged for review.
